# Dependency policy

Use Go 1.27.2 for local validation, CI and release builds. Module-proxy metadata refreshed on 2026-10-15 identifies Cobra 1.10.2, Testify 1.12.1 and sigs.k8s.io/yaml 1.6.0 as current; these updates pass local race and request-contract tests.

Keep `k8s.io/api`, `k8s.io/apimachinery` and `k8s.io/client-go` aligned. The maintained **v0.37.1** set is adopted after the source/API-contract evaluation recorded in the [upgrade assessment](../compatibility/evidence/2026-10-16-client-upgrade-review.json). Go 1.27.2 satisfies these modules' Go 1.26 requirement. The floor remains OpenShift 4.14 / Kubernetes 1.27, using the approved source-based assumption for unavailable older clusters. The new taint-helper arguments retain baseline matching, and explicit toleration-operator validation rejects newer semantics. A per-client JSON constructor prevents ambient client flags from changing the wire protocol; no global feature-gate state is changed.

Final local validation passes 356 race tests/subtests at 77.3% coverage, vet, module verification, an empty tidy diff and security/vulnerability checks. This adopts the dependency set in source; it does not qualify a release. The native artifact passed all 22 required scenario IDs on OpenShift 4.21.36; see the [current live results](client-upgrade-live-tests.md). The remaining release/version/platform matrix is tracked separately. Dependency or production-source changes invalidate the reviewed hashes until their actual delta is reassessed; prior binaries' results are not transferred.

JSON is forced for both requests and responses. The checked-in Kubernetes 1.27 baseline catalog prevents newer pod fields from silently entering ordinary conversion. These local checks do not prove old-server compatibility.

JSON is the canonical report. PDF is optional (`--report-path ''` disables it). Retain jung-kurt/gofpdf temporarily to preserve rendering; its upstream is archived. go-pdf/fpdf is also archived, so it is not an appropriate maintenance replacement. Any renderer replacement must pass long-name, multipage, content and rendered-layout regression checks before adoption. No external URL, image or font loading is used by report generation.

CI pins all Actions to resolved commit SHAs and security scanners to released versions. `go vet` and gofmt serve as the Go lint gates. Dependabot groups the three Kubernetes modules and the security transport libraries. No `dep`, legacy download shell pipeline, floating scanner branch, deprecated Actions output commands or archived release Action is used. Release jobs build with version, commit and deterministic commit-time metadata, attach SHA-256 checksums, and create only a draft after qualification. Publishing remains a maintainer action.

`tools/release_gate.py` requires actual OpenShift evidence per newer required minor and shipped binary SHA-256, tied to the exact revision, fixture tree and dependency file. Explicit 4.14–4.20 source-review assumptions require matching production/dependency/fixture hashes, completed assessments and no unresolved applicable findings; they never become integration passes. Simulated, skipped, missing, stale or incomplete actual rows block release. Refresh the released-minor inventory before each release; it currently includes 4.14 through 4.22 and a development smoke row.
